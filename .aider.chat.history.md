## 🎯 Project Strengths

### 1. **Modern, Clean Architecture**
The separation into **UI**, **Network**, and **Audio** layers is textbook separation of concerns. Each module has a single responsibility:
- `internal/ui` → Pure presentation (Bubble Tea + Lip Gloss)
- `internal/network` → Protocol handling (Codeberg API, SoundCloud parsing)
- `internal/audio` → Decoding/transcoding pipeline (Oto + go-mp3 + FFmpeg)

### 2. **Smart Transcoding Strategy**
The **FFmpeg pipe approach** (`ffmpeg -i pipe:0 -f mp3 pipe:1`) is elegant:
- Zero temporary files
- "Instant-on" playback for unsupported formats (M4A/AAC)
- Leverages streaming stdin/stdout — perfect for terminal apps

### 3. **Proactive UX Details**
- **Duration probing via `ffprobe`** before playback solves the classic "00:00 / 00:00" streaming problem
- **Vendored dependencies** (`-mod=vendor`) enable truly offline builds — great for reproducibility
- **Responsive TUI** with automatic resize handling

### 4. **Practical Format Support**
| Format | Handling |
